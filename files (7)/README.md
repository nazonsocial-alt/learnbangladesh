# Learn Bangladesh (বাংলাদেশকে জানুন)

> Learn your country. One lesson a day.

বাংলা-প্রধান, গেমিফাইড বাংলাদেশ শেখার প্ল্যাটফর্ম: ৬৪ জেলা চ্যালেঞ্জ, পাসপোর্ট স্ট্যাম্প, কুইজ ও সার্টিফিকেট।

## প্রযুক্তি
Next.js · TypeScript · Tailwind CSS · Supabase (PostgreSQL, Auth, Storage) · Vercel

## অবস্থা
| ধাপ | অবস্থা |
|---|---|
| ১ পরিকল্পনা, ২ UX | সম্পন্ন |
| ৩ UI ডিজাইন সিস্টেম | সম্পন্ন (`app/globals.css`, `components/`) |
| ৪ ডেটাবেস | সম্পন্ন (`supabase/migrations/0001–0007`) |
| ৫ ব্যাকএন্ড থেকে ১০ ডিপ্লয়মেন্ট | বাকি |

পেজ ও রুট এখনো নেই (ধাপ ৬), তাই `npm run build` এখন চলবে না।

## ডেটাবেস সেটআপ
Supabase SQL Editor-এ `supabase/migrations/` ফোল্ডারের ফাইলগুলো ০০০১ থেকে ০০০৭ ক্রমে চালান।

## লোকাল চালানো
```bash
npm install
cp .env.example .env.local   # মান বসান
npm run typecheck
```

## কনটেন্ট ও মিডিয়া নীতি
- কপি করা বা কপিরাইট করা লেখা নয়; সব তথ্যের সূত্র থাকবে।
- মিডিয়া শুধু পাবলিক ডোমেইন, ওপেন লাইসেন্স, মৌলিক বা ব্যবহারকারীর আপলোড। লাইসেন্স ও সূত্র ছাড়া প্রকাশ করা যায় না (ডেটাবেস নিজেই আটকায়)।
- কোনো জেলা রিভিউ ও ২টি সূত্র ছাড়া প্রকাশ হয় না।
